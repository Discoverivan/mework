# Security policy

## Supported versions

Security fixes are applied to the latest published release and the current `master` branch.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

## Reporting a vulnerability

Please report security vulnerabilities through GitHub's private vulnerability reporting flow:

1. Open the repository **Security** tab.
2. Choose **Report a vulnerability**.
3. Include the affected version, reproduction steps, impact, and a proposed mitigation if available.

Do not open a public issue for an unpatched vulnerability and do not include credentials, tokens, private keys, or personal data in the report.

We will acknowledge a report after triage and will keep the report private while a fix is prepared.
